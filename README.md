# QA Path 🐞

**A free, plain-English course from zero to your first junior QA job.**

Created by **Avinash Dangol** to help beginners start a career in software testing.

👉 **Start learning:** https://avinashdangol.github.io/qa-path/

## What you will learn

28 lessons in 7 modules:

1. **QA foundations** – what testers do, types and levels of testing
2. **Manual testing skills** – test cases, boundary values, bug reports, exploratory testing
3. **How the web works** – HTTP, browser DevTools, API testing with Postman, Agile and Jira
4. **Coding basics** – setup, JavaScript/TypeScript essentials, Git and GitHub
5. **Playwright automation** – locators, assertions, Page Object Model, CI with GitHub Actions
6. **AI skills for QA** – using AI for test cases, test data and automation (safely)
7. **Getting the job** – ISTQB Foundation, portfolio projects, CV, LinkedIn and interview practice

## How it works

- Each lesson has a short explanation, a practice task and a quiz question.
- Click **Mark as passed** when you finish. Your progress is saved in your browser.
- No sign-up, no ads, completely free.

## Run it yourself

It is a single HTML file. Download `index.html` and open it in any browser.
